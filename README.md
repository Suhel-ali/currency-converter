# Currency Converter

A Django-based currency converter web application that allows users to
convert currencies and manage their conversion history, favourites,
and feedback.

## Features

- Currency conversion
- Multiple currency support
- User registration
- User login and logout
- Conversion history for registered users
- Favourite currencies
- User feedback
- Responsive interface
- Django built-in authentication
- Django admin panel

## Technologies Used

- Python
- Django 6.1
- HTML5
- CSS3
- Bootstrap
- JavaScript
- SQLite
- Requests
- Pillow
